2. World frame

The 4 tags closest to the image corners become the world corners. Measure the distance between the tag centres with a tape measure. Convention: the top of the image is +y; use rotation/mirror if the camera is mounted differently.

Extra landmarks

Once the homography is valid, unknown tags lying on the floor can be measured and added as landmarks: the world can still be computed when a corner is hidden.

3. Robots

Assign each robot to its tag

"Identify" spins the robot in place for a moment (command on its topic) and keeps the tag that rotated. If the tag already belonged to another robot, the two are swapped. You can also type the tag by hand.
