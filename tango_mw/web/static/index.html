2. Repère du monde

Les 4 tags les plus proches des coins de l'image deviennent les coins du monde. Mesurez au mètre la distance entre les centres des tags. Convention : le haut de l'image est +y ; utilisez rotation/miroir si la caméra est montée autrement.

Repères supplémentaires

Une fois l'homographie valide, les tags inconnus posés au sol peuvent être mesurés et ajoutés comme repères : le monde reste calculable si un coin est masqué.

3. Robots

Associer chaque robot à son tag

« Identifier » fait pivoter le robot sur place quelques instants (commande sur son topic) et retient le tag qui a tourné. Si le tag était déjà attribué à un autre robot, les deux sont échangés. Vous pouvez aussi saisir le tag à la main.
